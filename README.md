## Featured Projects

### Web Security Header Auditor
Audits commonly deployed HTTP security headers and identifies missing controls such as CSP, HSTS, Referrer-Policy, and X-Frame-Options.

### SOC Log Anomaly Detector
Analyzes SSH authentication logs and highlights repeated failed-login activity by source IP.

### DFIR File Hash Triage
Calculates SHA-256 hashes for evidence files and checks them against analyst-provided IOC values.

### Phishing & URL Detection Tool
Security-focused phishing/URL investigation project using OSINT and threat-intelligence sources.
